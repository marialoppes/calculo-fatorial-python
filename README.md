# 🔢 Cálculo de Fatorial em Python

Projeto acadêmico desenvolvido durante o curso de **Ciência da Computação**, com o objetivo de praticar conceitos básicos de programação e utilização de funções da biblioteca padrão do Python.

## 📌 Sobre o projeto

O projeto consiste em um programa que solicita ao usuário um **número inteiro entre 1 e 10** e calcula o seu fatorial.

Para realizar o cálculo, foi utilizada a função `factorial()` da biblioteca `math`.

Após o processamento, o resultado é apresentado no terminal.

### 💡 Exemplo

Para o número `5`:

```text
5! = 120
```

## 🛠️ Tecnologias utilizadas

* Python
* Visual Studio Code
* Biblioteca `math`

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram utilizados e praticados conceitos como:

* Variáveis
* Entrada e saída de dados
* Conversão de tipos (`int`)
* Operações matemáticas
* Importação de bibliotecas
* Utilização da função `math.factorial()`
* F-strings
* Exibição de resultados no terminal

## ▶️ Como executar

1. Certifique-se de ter o **Python** instalado em seu computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no **Visual Studio Code** ou em outro editor de código.
4. Execute o arquivo:

```bash
python calculo_fatorial.py
```

5. Digite um número inteiro entre `1` e `10` quando solicitado.

6. O programa exibirá o resultado do fatorial no terminal.
